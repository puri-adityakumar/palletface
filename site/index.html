GET STARTED

Small by design.

Preparing for public release. After npm publication, install the package and render SVG in a modern browser or Node application. ESM and TypeScript declarations; no framework required.

npm install dither-face

All eight styles are in the gallery above. Letter styles use the first ASCII letter or digit of name after accent normalization; a blank playground name uses the seed. Unknown initials use ?. The seed still drives the design.

Embed the SVG as an image data URL. Use a descriptive alt, or an empty one when the user's name is already adjacent. Full API and examples ↗

OPTIONS & LIMITS

Plain SVG. Clear rules.

style defaults to pixel-sprite. px defaults to 80 and must be positive and finite; the playground offers 48, 80, 128, and 192. name is optional and affects only letter styles.

ASCII styles use your system monospace font, so glyph shapes can vary between platforms. This is a 0.x preview: minor releases may change APIs or output. Pin an exact package version when persisted identities need to stay fixed.

No avatar service, account, downloaded font, analytics, or runtime dependency. Seed hashing is not cryptography: similar avatars and collisions are possible. An avatar is not proof of identity.
