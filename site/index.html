GET STARTED

Small by design.

Install the package and render an SVG anywhere JavaScript runs.

npm install dither-face
import { ditherFace } from 'dither-face'

const svg = ditherFace('user-42', {
  style: 'pixel-sprite', px: 80
})

All eight styles are in the gallery above. Choose a fixed seed and style to keep an identity stable. Letter styles use the first character of name, when provided; the seed still drives the design.

OPTIONS & LIMITS

Plain SVG. Clear rules.

style defaults to pixel-sprite. px defaults to 80; the playground offers 48, 80, 128, and 192. name is optional and affects only letter styles.

ASCII styles use your system monospace font, so glyph shapes can vary between platforms. This is a 0.x preview: minor releases may change APIs or output. Pin an exact package version when persisted identities need to stay fixed.

No browser service, account, downloaded font, analytics, or runtime dependency.
